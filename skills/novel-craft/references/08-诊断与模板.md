# 诊断与模板

前面各册讲"该怎么做"，这一份讲"出事了查哪儿"，并给能直接复制的表和能直接跑的脚本。

## 一、诊断顺序

**先量，再查结构，最后才动文笔。** 一上来改句子，是最常见的白干。

0. **先当读者读一遍**（这一步不查任何东西）。从头到尾只看，不拿笔改，单独记一行：「哪里想跳过」「哪里回头翻了」「哪里放下了」。这三样是读者真实反应，脚本量不出、结构表也推不出。**跳过＝水，回头翻＝前面没交代清，放下＝钩子断了。** 读完再进下面的量。
1. 跑 `scripts/check_text.py`，看句长趋势和数字密度。
2. 查结构：三压缺哪条、这一卷用掉几条边、卷末离主线还差几步。
3. 才轮到改句子、换词、加描写。

**第 0 步为什么必须在自己动笔改之前**：一旦开始逐句改，就再也读不出"第一次读的人"的体感了——你会记得每句为什么这么写。找别人读一遍更好；没有别人，就趁自己还没进入修改状态时先读。

### 加人前后对照（一次性验收）

加完人填这张，专门分清"真补洞"和"只多了记录"：

| 项 | 加人前 | 加人后 | 性质 |
|---|---|---|---|
| 成长线有具名执行者的台阶 | | | 真补洞／没变 |
| 情节主表行数 | | | 真增戏／只加坐标 |
| 新增行是冲突还是交代 | | | 戏／桥 |
| 爽点条数 | | | 看加的是哪种人 |
| 承重边变形次数 | | | 可核性上升 |
| 需反查的行数 | | | 维护成本上升 |
| **五项增量**（台阶／承重边／爽点／新案／新场面） | | | **连续两次全零才停** |

**判据**：前三行至少一行是"真补洞／真增戏"，否则这次加人只是把表填满了。加的是规矩来源或同行者，爽点没变是正常的；**加的是对手或镜像，爽点还没变，说明那场对手戏没按三要件写**。别拿坐标变多当成功。

**台阶已满时**："有具名执行者的台阶"这一行不再变化，改看三样——补了哪类结构洞／有没有开出一种新型关系／新增行是戏还是桥。

**"有价值"和"还能加"分开判**：本表判这次加人有没有价值；五项增量判还要不要继续。**连续两次五项全零才停手**。但目标字数还差得远、案数不够时，即使结构指标全零也**不许收工**，该去开案、加群像。

**加对手却没涨爽点，未必是失败**：按"输要写足、办不成不能赢"，对手新增的那一案若安排主角输，爽点条数不会动。先看那一案是不是输案，再判。**新人也可能是给老边补第三节点，看他激活了哪条老边**，别只数他自己那条边。

## 三、表模板（按名字定位，不数第几张）

> **引用纪律**：本文件与其他细则提这些表，一律用表名（「情节主表」「人物卡」「案目标清单」…），不写「第 N 张表」。表增删或换序不该让任何指针失效；发现按序号引用，直接改成表名。

人物、戏纲、情节是三张联动的表：**人物卡**管"这个人立没立住"，**案目标清单**管"这一案有没有立人物场"，**情节主表**管"这一场干了什么活、被后文哪几处引用"。规则不落进这三张表，就还只是判据文字。**戏类只有三类**；立人物场不是第四类，是场面戏／主线戏按 `功-06` 挑出来的承重场。

**填表顺序**：先在「案目标清单」写「开局规矩」并分派四类在场人，再回来写本表这一行「事」；本表其余列都是坐标，不负责生成。没立规矩就先写「事」＝硬编（见 `references/01a-立项与情节.md`「一案的生成顺序」）。

**每一行按戏类填坐标**：主线戏填成长线台阶与设定依据；支线戏填案号／人物线／伏笔编号；场面戏填场面类型**并挂功能编号**。在场人、格位号、边号是回查的钩子。一章一行，不写心理不写描写。**"两栏皆空"不等于注水**，只有不属于三类戏才算。

**功能编号（固定码表，场面戏必填，含立人物场）**：`功-01` 推进命题／`功-02` 换口味／`功-03` 立世界规则／`功-04` 闲笔伏笔／`功-05` 给人物一个无关主线的动作／`功-06` 立人物场。没挂功能编号的闲笔才叫注水；不设百分比上限，按连续三案趋势判（见 `references/01a-立项与情节.md` 一 →「第三步」）。

**回声编号（立人物场必填，其余按实填）**：三种写法——
- 立人物场填 `被 ××、××、×× 引`，**至少三处**，三处都要能在主表里反查到行；凑不满三处，这场退回普通场面戏。
- 引用前场填 `引 一-02`。
- **三处必须换领域、升代价**：编号后跟「领域·代价档」（如 `四-09 军令·抗命`），按「案目标清单」的「领域」列分属三个领域，代价按吃亏／受罚／抗命／送命递增。**三处同领域同量级，判原地打转**，不许算立人物场（见 `references/01a-立项与情节.md`「情节从哪来」）。**中篇／承受驱动型豁免**：可只填一次顶格兑现（见同册「承受驱动型」），并在回声编号里注明「顶格·单次」。

**立人物场算承重戏**：戏类列仍填主线／支线／场面之一，**靠 `功-06` 识别**，回声编号凑够三处；主角没赢、不推进命题也算数，不许按爽点三要件删。它的另一半落在**人物卡**（脾气、三件事、固定代价）。

**其余文档只存编号**：按台阶筛＝成长线；按卷筛＝逐章细纲（每 6—8 章一段，段首标"这一段办什么"）；按人筛＝人物线；按格筛＝格位表；**按功-06 筛＝全书立人物场清单**。**卷末转折单独列**，别混进表里。

编号全局唯一、不重排；改设定或砍案后按编号反查受影响的行。

### 常量与伏笔台账（验收第 6、14 项的载体）

| 编号 | 类型 | 内容 | 首次出现的情节编号 | 兑现的情节编号 | 状态 |
|---|---|---|---|---|---|
| 物-01 | 物理量 | 连廊跨度十二米四 | 二-03 | 三-05 | 已核 |
| 知-01 | 知情格 | 李萍早想到大汗会要他打宋 | 一-01 | 四-28 | 已兑现 |

**类型**：物理量／知情格／道具／承诺／称呼口径／**时间量**（「煤够烧九天」这类跨章递减的量：须记起算格号与日期，递减按格位表日期差核，不按章数核；折算口径见 `references/12-故事时间线.md` 第二节）。凡"跨章不许重算"的东西都进这张表。

**三条硬规矩**：①每行必须有首次出现与兑现两处编号，只有首次出现的叫**悬空伏笔**；②改一处，按编号反查主表里所有含它的行；③**悬空超过十章的，当章回收或直接删**——台账只进不出，长篇写到第三十章就会积一堆再也用不上的伏笔。

**超期怎么查**：首次出现的情节编号换算成章号（`情节编号`含卷号与序号，章号按格位表对应格取），与当前章号相减；差值超过十的列入**超期清单**。每卷收尾时出一次清单，逐条判：还能接上就排进后续案，接不上就删行、并在主表对应行把伏笔编号划掉。**不许因为"埋了这么久总该兑现"硬凑一场**——硬凑的兑现比不兑现更伤，读者看得出来是在还债。同类技能把这一步做成脚本，我们靠台账人工核，但规矩一样：超期不是"该收"的信号，是"该决定收还是删"的信号。

情节主表的"常量/伏笔编号"列只引编号、不抄内容。

**道具是一条线，不是一个点**：道具另记 `编号｜道具｜首次出现的情节编号｜每次转手的情节编号链｜每次的功能｜最终兑现｜状态`。一条道具线至少三次出场、其中至少两次功能不同。只有"出现＋兑现"两列的是伏笔，别混。

**「开局规矩」列先填，再填其余列**：六选一（世界规则／组信条／授艺交换／本事限制／实物用法／当场划的道儿），并注明由它分派出的四类在场人（守／违／只看见一半／在旁看着）各是谁。这一格空着，主表那一行「事」就是硬编的。详见 `references/01a-立项与情节.md`「一案的生成顺序」。 **这一列还要记改写链**：谁把它改成了什么、谁又用更高一层规矩顶掉，每改一次对应主表一行戏。

**示例分派（修订版《射雕英雄传》第 2 回）**：开局规矩＝斗酒"各位共喝七碗，贫道一人喝六碗"＋组信条"我们信得过焦木大师，他说没有就是没有"｜守的人＝江南七怪（宁可认输不改口）｜违的人＝丘处机（认输后仍要交人）｜只看见一半的人＝丘处机、焦木（地窖、随从是女子）｜在旁看着的人＝完颜洪烈（"留神倾听，暗自记忆"，逐一报出七人名号本事）。

**后四列数场数，不分摊章数**。`立人物场`不是第四类戏，是从场面戏／主线戏里按 `功-06` 挑出来的**承重场**，单列只为计数与查回声，**不与前三类相加**，也不占场面戏配额；示例里那一场场面戏就是立人物场，不是另加一场。

**每有一个立人物场，回「情节主表」核一项**：那一行的回声编号是否凑够三处、三处能否反查到行。凑不够就别算立人物场，改记场面戏。

**示例分派（体制小说，《省委书记》第 40 回）**：开局规矩＝贡开宸职务指令"没得到K省一把手同意前谁也无权恢复马扬工作"（⑦）＋医疗常理｜守的人＝马扬本应服从、黄群按医生本分｜违的人＝马扬以"大山子命运、3.4亿投资"当众推翻禁令、电话封局长口、以任免权逼院长定"最高机密"｜只看见一半的人＝贡开宸察觉改口异常却暂不动声色｜在旁看着的人＝公安局长向贡开宸私下汇报，带出公安系统并揭破口径不一。四类人全由"职务权责"分派，无一人靠硬加。

**一案三撞另定**（开场谁先动手／中盘换谁／收场谁松口），见 `references/02-爽点与节奏.md`。

**每案先答两问，答不出这一案还没生成**：①这一场怎么算赢、**道儿是谁当场划下的**（第 2 回丘处机"划下道儿来罢"→ 斗酒"各位共喝七碗，贫道一人喝六碗"）；②上一案留了什么可数缺口，本案是不是去补它（第 12 回"降龙十八缺三掌"→ 练"满天花雨"→ 买针）。**划下的规矩可以被更高一层规矩推翻**：七公认输后仍说"扶危解困，跟输赢可不相干"，戏就又开一层，不必另找对手。

**容量核算**：台阶数 × 每台阶案数 × 每案章数 × 单章字数 ≥ 目标字数。不达标就是设计没做完。

**相邻两案不许同领域**；领域一换，阵营卡往往也得换。每案先开阵营卡，一次带 3—8 人，详见 `references/01b-矩阵与加人.md` 三「成组进场」、`references/01c-格位与容量.md` 五。**趋势判据**：连续三案没有场面戏／立人物场＝太紧；连续三案场面戏过半＝注水。

**阵营卡不只列人**：`01b` 阵营卡那句"这套人共同的规矩"，必须配**一件违反它就当场出事的事**（谁违反、谁付代价、挂哪个情节编号）。人是被这件事推上场的，不是"再加一个有意思的人"加出来的。第 3 回蒙古主客之礼 → 完颜洪熙撒钱辱童 → 郭靖掷金币 → 掷矛 → 哲别一箭，一条组规矩当场生成一整场戏并带出新人物（原文见 `references/04-专业质感.md`）。

### 人物卡（每人一张，核心／扩展／有名群像都要）

| 人物 | 层（核心／扩展／有名群像） | 阵营卡 | 核心脾气（写成动作句） | 由它生成的三件事（情节编号） | 固定代价 | 后文三处回声（情节编号） | 立人物场（编号） | 自我辩护／真假 |
|---|---|---|---|---|---|---|---|---|
| 郭靖 | 核心 | 蒙古／江南七怪 | 客人给的东西不拿，问话不说谎 | 一-02 挨鞭不吐、一-05 两次拒金、四-03 守信抗命 | 处处吃亏，被当呆子 | 四-09 军令·抗命、六-12 家国·送命、八-31 天下·顶格 | 一-02 | "妈妈说的"，真 |

**这张表就是「脾气→动作」的落点**，不再另建文件；也是无金手指作品「核心机制」的载体（见 `references/01a-立项与情节.md` 二）。四条填表规矩：

1. **核心脾气必须能写成动作句**，写不成就是形容词，人物没立住。
2. **三件事＝脾气近处直接生成的动作**，各挂一个情节编号；**三处回声＝后文远处引用这条脾气生成的戏**。两格不许填同一批编号，近因与远因要分开；**三处回声还须分属三个领域、代价递增**，编号后跟领域简写（见「情节主表」示例），否则只是给同一场戏贴三次标签。
3. **固定代价写具体吃亏**，不写"性格孤僻"这类评语；代价要能在正文里真吃亏一次。
4. **立人物场编号回指「情节主表」**，且那一行的三处回声必须能反查到行；自我辩护分真假（他自己怎么解释／读者看得出是不是借口）。

**带本事的人物，在同一页另记五件**（不另建表）：`本事｜交换条件｜不许做什么｜留了什么可数缺口｜一句当时听不懂的话`。五件各挂情节编号，缺口那件必须指向案目标清单的下一个案，那句话要跨到终局（见 `references/01a-立项与情节.md`「授艺序列」）。金手指四限制只管"能不能用"，管不了这五件。

**有名群像减负**：只填前三列＋立人物场，三件事与三处回声可空；核心层与扩展层才填满。

**验收**：删掉"三件事"这一格，主表里对应的三行戏就该消失。删不掉，说明脾气只是贴的标签。

### 章节元数据卡（每写完一章就填，写后回写）

**这是唯一一张"写正文时才填"的表**，其余各表都在设计阶段填。**一章一张，写完立刻填，不许攒**——攒十章再回写，人物状态早忘了，就会出现"同一个人被写成两个人""伤好了又流血"这类错（2026-11 实跑稿里真发生过）。

| 项 | 填什么 |
|---|---|
| 章号／格号／日期区间 | 第 N 章、格 N、起日 → 止日（章内跨几日，见 `references/12-故事时间线.md`） |
| 本章办成什么 | 一句话，盖住主表那一行仍说得通 |
| 信息点 | 新增几条、读者新知道了什么，每条一句；超过 4 条考虑拆章 |
| 动到的承重边 | 边号（承 1—承 12）；没动写「—」。连续两卷没动的边按「每卷边折旧回填」表核 |
| 伏笔 | 推进哪条／回收哪条／新埋哪条，只写编号（物-xx、知-xx），不抄内容 |
| 人物状态变化 | 谁知道什么（知情格变化）、伤／物／身份变了什么。**这一格是防人设崩的唯一记录** |
| **在场人与位置**（必填） | 本章出场的有名人物，各自**此刻在哪**、**知不知道本章的关键信息**。例：`梁守业（省城宾馆，知调令在路上）／常贵（厂门口等人，不知调令）／陈砚秋（知郝点将梁，不知原话）`。**配角即使本章毫无变化也要写位置**——漏记就会出现"上一章在厂里、这一章在省城"这类跨章硬伤（2026-11 实跑稿发生过三处：配角落位错、配角知情越界、其连锁） |
| 章末钩＋下章接什么 | 钩一句原文；下章开头接哪一句（`references/13-章节质量闸.md` 查钩位） |
| 时间跨度 | 起日→止日；与本章格位日期是否一致，跨日是否越过相邻格 |

**四条硬规矩**：

1. **写完一章当场填，最迟不超过下一章开头。** 补填等于凭记忆重建，必错。
2. **状态只记"变化"，位置必须记全**：人物状态那一格写"本章结束时与上一章不同的地方"，全貌在人物卡里；但「在场人与位置」要写全本章出场的人，哪怕他一点没变——不记位置，下一章读卡也核不出来。
3. **伏笔只写编号**，内容在主表与台账里各存一份，这里不建第三份副本。
4. **下一章开头先读上一章这张卡**，再落笔——这是"章际承接"的人工部分，脚本只能提示不能判。

**验收**：拿这一章卡片去对下一章首段，三样必须接得上——人在哪、什么姿态、知道什么。接不上就是断，回正文改，不许改卡。

## 四、自检脚本

脚本都只用标准库，不用装东西：`check_text.py`（字句级）、`check_structure.py`（结构层）、`check_emotion.py`（情感落点表）、`check_timeline.py`（时间线）、`check_chapter.py`（章级质量闸）。

**脚本不是使用前提**。整套方法可以纯对话走完：各表用文字填、章节元数据卡写一章填一次、结构用算术核、时间线用对读。脚本只干一件事——把能机械算的算掉，省人工。**不想开命令行就跳过**，判据仍在文档里；要跑就按下面来。

**其余四个脚本的调用命令**（字句级 `check_text.py` 的命令与判读见本节后文；各脚本参数与能力边界也写在各自文件头部）：

```
python check_structure.py 边数 6 8 5
python check_structure.py 容量 4 5 12 3200 300000
python check_structure.py 格位 格位表.md
python check_structure.py 占比 46 12 24 210
python check_emotion.py 落点表.md
python check_emotion.py 目录/ --all
python check_timeline.py 格位表.md 正文目录/
python check_chapter.py 正文目录/ --all
```

**脚本不挑位置，正文也不用搬。** 五份脚本放哪都能跑，不必放在技能目录里，正文目录同理。两种跑法都行：进到脚本所在目录执行上面的命令，或直接给脚本完整路径——`python <脚本所在目录>/check_text.py <正文目录>/第一章.md`。Windows 路径带空格时加引号。**唯一要留意的是相对路径的基准是"你当前所在的目录"，不是脚本目录**；报「找不到文件」时先换成绝对路径试一次。

**编码也不用先转。** 五个脚本读文件时按 BOM → UTF-8 → GB18030 依次试：Word 另存出来的 GBK、记事本存的「Unicode」（UTF-16）都能直接读，读完打一行【提示】说明实际用了哪个编码，原文件一字不动。连 GB18030 都解不了才报 E03——中文文本极少走到这一步，多半是把 `.docx`／`.pdf` 当正文传了。

`check_emotion.py` 的输入表**唯一模板**在 `references/10-文笔与情感层.md` 第五节「情感落点表」，本节不存副本。表头须含「主感」与含「落点」两列；没认出来脚本会明说「不判通过」，不会把空结果当合格。

`scripts/check_text.py`：

```
python check_text.py 正文/第一章.md
python check_text.py 正文/ --all          # 按章号自然排序，直接给趋势警报
python check_text.py 正文/第一章.md --json
```

量什么：汉字数、字符数、段数、叙述句均、对话句均、段均、半角引号、孤行标点、短句连排、数量短语密度。

**口径**（要跟手工量法对齐，不然数对不上）：
- 字＝去空白后的可见字符，**含标点**
- 叙述与对话分开量，引号内文字只进对话
- 句子按句号／问号／叹号／省略号切分
- 数字密度＝每多少字出现一个"数字串＋量词"

### 判读

- 批量模式会合并连续递减段，长度满三章才报一次警报（如"连续 5 章走低，12.5 → 10.3"）。
- **20—24／8—12／26—34 是常规章参考值，不是硬指标。** 几份实测稿都在 10—18 之间（实测数据见 `references/16-实测与维护记录.md` 第一节），冷叙事和番茄短句章通篇偏低是风格。
- **看趋势比看绝对值有用。** 用 `--all` 出表，连续三章走低才是警报。
- 半角引号：源稿用半角是约定，**出排版件前必须转中文弯引号并复跑，排版件应为 0**。
- 孤行标点必须为 0。
- 每字间隔低于 30 提示数字偏密；低于 25 基本要拆章。

### 实测基准（已移至附录）

2026-11-05 三份稿的句长、段均、数字密度实测值，原文一字未删地移到了 `references/16-实测与维护记录.md` 第一节。

**这里只留判据：三数是参考不是硬指标，看逐章趋势，连续三章走低才是警报。** 需要核对参考值当年怎么量出来的，再去附录。

**模仿的验收**：每一项都能指回成品哪一回；指不回的是自己补的，单独标出来。**模仿的是密度机制，不是情节。** 拿成品当尺子时，量的是"一案能装多少个不同系统的戏"，不是单章字数。

### 文风五维表（对标档专用，回答"能不能写成另一种笔法"）

上表取的是**结构密度**，取不到笔法。要写成另一种文风，另外抽五维，办法是拿对标成品的一段正文实测，不靠形容词形容：

| 维度 | 从成品怎么取 | 落笔怎么用 |
|---|---|---|
| 叙述句均长 | 取一章正文，剔引号内文字按句号切分，算均值 | 写自己这章时按此区间，不套默认 20—24 |
| 对话句均长／占比 | 只统计引号内文字，算均值与句数占比 | 对白多的文风（如王小波式反讽）占比自然高 |
| 形容与比喻密度 | 数每千字的形容词叠用与明喻暗喻处数 | 汪曾祺式淡雅低、张爱玲式繁复高 |
| 感官偏好 | 看这段主要靠哪种感官落细节（视／听／触／嗅） | 定主感官，一章里别五种轮着用 |
| 人称与时态 | 第一／第三人称、过去／现在时 | 定了不中途换；第一人称可自责下结论（`03` 〇节） |

**取法**：从对标成品挑三章（开头／中段／结尾各一），各取 500 字，按上表量出三个值，取中位数填进立项一页纸。**别拿一章当全书**——同一作者不同章也会漂。

**冻结样本**：从对标成品摘一段 150—250 字，必须含一处对话和一处动作，给用户确认后冻结。它只约束笔法（节奏、用词、标点习惯），不约束情节；情节该按 `01a` 的三条戏走。样本冻结后**不许改**——改了基准，后面每章的去 AI 味就没有对照物了（同类的做法里，这一步被称作去 AI 味最关键的单一杠杆）。

**每章怎么用**：写单章前读一遍冻结样本；写完按 `03` 第七节去 AI 味时，**先对着样本逐句改**，再过词表，最后跑脚本。脚本的句长参考区间只对默认档有效，对标档拿样本当尺子——`03` 第一、二节的"警报"在对标档改看逐章与样本的偏离趋势，不拿绝对数判病。

**验收**：把你的第一章和冻结样本并排读，若"像出自两个人的手"——不是情节不像，是用词习惯、句子长短、标点节奏不像——先改笔法再往下写；此时改一章的代价远小于改十章。



## 六、最小可行集（第 0 步＋五件事）

**主文件第 0 步「定来路」必做，不能跳**：先定模仿还是新做，填完立项参数表，再往下走。

规则多，第一遍别全上。下面五步走完就能**试写第一章**（验证路子对不对）；**这不等于可以开连载**，整本书设计完成的标准见 `references/05-改稿核账.md` 第十节。

1. 一句话命题＋四到六步成长线（每步一个动作＋打掉一条旧信念）
2. 核心人物三到五人，按 C(C−1)＋2CE＋X 建边；知情矩阵先填五到十格；**每人先在「人物卡」写一句能演出来的核心脾气**（只填前三列，三件事与回声留到第二遍）
3. 情节主表建壳：每个台阶至少两行戏，填事＋章末钩＋台阶＋戏类＋功能编号
4. 格位表给这些戏排时间、地点、视角，编号连续
5. 跑验收清单，把"设定依据／边号／格位号"回填进主表

分型开关、爽点分级、边折旧、文笔三项指标、平台排期，都是第二遍以后才加的。

## 七、反模式清单（见一次踩一次）

- 把"有动作"当"在场"，前史永远写不出来
- 编外格导致两套编号打架
- 加人后不回头改"全书唯一"表述
- 外部审稿清单直接照改（错字清单先检索再动手，真去替换会把对的改错）
- 删除类操作不验锚点唯一性，一次吞掉四章
- 设定越平衡越不想写——平了就停手，转入写稿
- 一上来改句子。没量、没查结构就润色，是最常见的白干
- 把句长区间当硬指标。冷叙事章通篇偏低是风格，看趋势不看绝对值

**跳步诊断**：卡在哪一阶段，回该阶段的产出物补，不要往前硬写。常见的三种跳步——没填参数表就写命题、没开阵营卡就加人、没算容量就宣布"人全了"。

**每阶段三道通用闸门（必过，回 09／10／12）**：① **冲突裁决预检**——本阶段落地的发电机产出，是否与其他发电机抢了同一槽位（主回路代价槽被次回路抢／金手指限制被放宽／知情矩阵被视角写破），按 `references/09-仲裁层.md` 元优先级逐层查；② **情感落点预检**——本阶段关键处是否预留了情感落点（代价真吃亏／回声兑现／命题翻转击破／关系错位发生之一），按 `references/10-文笔与情感层.md` 验收清单逐项过；③ **时间线预检**（工序五起每章必过）——本章挂哪个格位日期、上章结尾人在哪什么姿态、本章每个硬天数能否折算回格位表，按 `references/12-故事时间线.md` 逐项过；**改稿／扩写后另做跨章回归，不许只跑 `check_text.py` 就宣布对齐**。任一未过，不进下一阶段。
