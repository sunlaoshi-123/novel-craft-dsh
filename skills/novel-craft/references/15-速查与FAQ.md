# 速查与 FAQ

> 只做索引与结论，**不另立规则**；任何一条与本文件指向的细则冲突，以细则为准。
> 用法：先在这里找到结论，需要细节再跳细则。

## 一、五分钟上手

| 你现在的情况 | 直接做什么 |
|---|---|
| 想写一本长篇 | 进「第 0 步：定来路」，说清三件事：写给谁、大概多长、对标哪本书或全新 |
| 只有一句话想法 | 先答三句（写给谁／多长／对标或原创），答出两句就够开工 |
| 正在写第 N 章 | 走「五、写单章」：时间线预检 → 文笔纪律 → 跑 `check_text.py` → 每五章跑一次 `check_chapter.py`（最长不超过一卷） |
| 要改稿或处理审稿意见 | `references/05-改稿核账.md`，先检索再动手 |
| 读者说越读越平 | `check_chapter.py 正文目录/ --all` 看逐章曲线与章末钩 |
| 时间线打架 | `references/12-故事时间线.md` ＋ `check_timeline.py 格位表.md 正文目录/` |
| 字数不够、写不厚 | `references/01c-格位与容量.md`「字数不够怎么办」；情节不够回 `01a`「情节从哪来」 |
| 撞上技能问题 | 整理一段描述（可附截图），地址见 `references/14-反馈与台账.md` 第三节 |

### 先按篇幅认路，别从第一条读到最后一条

四档的工序不同，**先对号，再只读该档要的那几份**。唯一的四档对照表在主文件「按任务分流」开头，本页不存副本——短篇关格位与容量，中篇简化格位、爽点粗配，长篇六道全跑，超长篇再加章节元数据卡与章级闸（细解见 `01c`「篇幅档」）。

## 二、常见报错与处置

| 现象 | 多半是 | 怎么办 |
|---|---|---|
| 找不到文件 | 路径写错、目录名带空格 | 路径加引号；先 `ls` 确认文件在 |
| 编码 | 文件不是 UTF-8（Word 另存、记事本 ANSI 是 GBK，记事本「Unicode」是 UTF-16） | **不用先另存**：脚本按 BOM → UTF-8 → GB18030 自动读，并打一行【提示】告诉你用了哪个 |
| 表格解析不到 | 表头缺关键列名、列数不齐，或干脆用列表写 | 表头须含关键列名（情感落点表要「主感」和含「落点」的列，格位表要「格号」列）；**全角竖线和缺分隔行会自动兼容**；用列表代替表格的写法不支持，得改成表格 |
| 日期识别不到 | 写法超出三级精度 | 完整日 `2026-11-07`／只到月 `2023.10`／月加旬 `2026.08下`（上中下底）都认；末格写「结尾」算无日期 |
| 提示「文件较大」 | 文件超过 8 MB，通常是全本合订 | 不是错；按卷拆开跑，或只跑单章。单章正文一般只有几百 KB |
| 章号识别不到 | 文件名没有「第N章」 | 改成 `第01章-xxxx.md` |
| 提示「占比类判据不启用」 | 关系对少于 60，属正常 | 不是错；此时只按定性规矩查 |
| 提示「无章号，不参与趋势判定」 | 文件名缺章号 | 属正常提示；改名后重跑 |
| 输出全是 0 或空白 | 传了空文件或全空白 | 确认文件有正文；空文件不报错，只统计为 0 |

**错误码对照**（脚本报错时先认这行，再说怎么改）：

| 码 | 含义 | 处置 |
|---|---|---|
| E01 | 找不到文件 | 路径加引号、先 `ls` 确认文件在 |
| E02 | 把目录当成文件传了 | 单章传文件路径；批量按文件头用法加 `--all` 并给目录 |
| E03 | 连 GB18030 也解不了（正常中文文本极少见） | 多半是二进制文件或加密文档；确认传的是 `.md`／`.txt`，不是 `.docx`／`.pdf` |
| E04 | 没有读取权限 | 换到有权限的目录，或先复制出来再跑 |
| E05 | 其它未预期异常 | 把整行连同命令按 `14` 整理成一段反馈 |
| E06 | 整张表无一行日期可解析 | 三级精度任选：完整日／只到月／月加旬（上中下底）；表头须含「格号／#／序号／格」和「时间／年月日／日期」列 |
| E07 | 参数要整数、填了别的 | 只填数字，不带单位或汉字 |
| E08 | 参数个数或写法不对 | 按文件开头用法重填；结构核账有「边数／容量／格位／占比」四个子命令 |

**输出怎么读**（五个脚本同一套标记）：

| 标记 | 意思 | 要不要改 |
|---|---|---|
| `【错误 E**】` | 脚本跑不起来 | 必改，按上面错误码表处置 |
| `【警报】` | 硬问题，判据没过 | 必改 |
| `【待核】` | 可能是克制写法，得人看一眼 | 人判后决定 |
| `【提示】` | 参考信息（空号允许、判据未启用等） | 一般不用改 |
| `【结论】` | 脚本给的判定结果 | 照结论走 |

**已知误报：报红但不用改稿的四种**。量具抓的是形式信号，下面是已知的系统性偏差，遇到先对号，别急着改正文：

| 现象 | 为什么不是稿子的错 | 怎么办 |
|---|---|---|
| 跨章九字重复串只命中「三月十二，门锁一把」这类 | 本子、匾额、合同上的常量原文，本来就该逐字一致 | 判允许，不改；常量以外的重复才处理 |
| 时间线报「第二天越界」，但这一章本来就覆盖两格 | 量具按「一章一格」取相邻格，不知道本章合并覆盖了下一格 | 格位表加「章」列声明（`12` 第一节第 6 条）；不加时它会报【待核】而不是【警报】，人判一句即可 |
| 章节强度千字值偏低、叙述句均只有 10—18 | 冷叙事、零度写法被词频系统性低估，是风格不是病 | 只看逐章趋势，连续三章走低才动结构 |
| 提示「占比类判据不启用」 | 关系对不足 60，属正常 | 不是错；改按定性两条查 |

四条之外报的红，默认当真，回去核原文。

## 三、口径速查

| 要查什么 | 结论 | 详见 |
|---|---|---|
| 篇幅档怎么分 | 短篇 1 万以下／中篇 1—8 万／长篇 8—30 万／超长篇 30 万以上 | `01c`「篇幅档」 |
| 一部书多少案 | 案数 ≈ 同时跑的线数 × 每条线跑过的领域数 | `01a` |
| 一案多大 | 8—20 章、1.8—3.0 万字；每台阶挂 3—6 案 | `01c` |
| 格位怎么编号 | 主格号连续；空号允许，**不补号**（补号会打断引用）。表头带「格号／#／序号／格」列、值写纯数字即可被识别，不必写成「格 3」 | `check_structure.py` 提示 |
| 多表混排怎么办 | 一份文件只放一张格位表；同一文件几张都从 0 起的表会让日期读成假倒序。量具提示「疑似多表混排」并按数据最多的那张验，**但应把主表摘出来单独存** | `01c` 第四节 |
| 关系对阈值 | 少于 60 对不启用占比判据；达到 60 启用，承重边 10—15% | `check_structure.py` |
| 时间线唯一口径 | 全书一条时间轴；章内跨日合法，跨章双轴要预警 | `12` |
| 一格能覆盖几天 | 本格起日到相邻格日**之前**的连续若干日；合并覆盖多格须在格位表加「章」列声明 | `12` 第一节第 5、6 条 |
| 台阶几步 | 长篇压到 3—4 步；超长篇 4—6 步 | `01c` 五 |
| 回声几处 | 三处，分属三个领域、代价递增；中篇／承受驱动型可豁免为一次顶格兑现 | `01a`「回声」、`08` |
| 章级检查多久一次 | 每五章一次，最长不超过一卷 | `13` 第三节第 4 条 |
| 设计文档该有多少 | 不超过正文的三倍；超了就砍工序（先砍逐章工作注、再砍元数据卡、最后降档），不砍正文 | `01c` 第 4 条 |
| 「唯一」表述怎么复验 | 抽词（唯一／从未／头一回…）→ 逐条对表（在场列／章序／日期区间）→ 判三种冲突 | `05` 第一节第二类 |
| 全书级要另查什么 | 合订后再查三项：同一个身体细节全书用了多少次／主角有没有做过与脾气相反的事／章题是不是取自本章原文 | `05` 第一节第四类 |
| 审稿意见怎么判 | 先分「漏洞」与「取向」：点名处原文有没有对应物证、落实后作品主张变没变；处置写三档（照改／认但另起一轮／不认回原件举证） | `05` 第六节 |
| 闸门有几道 | **时间线自身两道**：①写单章前预检 ②写完后回验。这是时间线内部的数，别与全书的闸门计数混着说 | `12` 第四节 |
| 情绪强度怎么判 | 看逐章曲线与章末钩位置；连续三章走低才警报 | `13` |
| 句长参考 | 叙述句均 20—24 字／对话句均 8—12 字／段均 26—34 字，是参考不是合格线 | `03`＋`check_text.py` |
| 脚本是不是必须 | 不是；纯对话也能走完，脚本只是量具 | 主文件「按任务分流」 |
| 反馈怎么发 | 一段描述＋可选截图，版本与时间自动带 | `14` |

**同一个规则只查一处。** 规则散在多份文件里时，认准下面的权威处；别处只做引用，不必重复读：

| 规则 | 权威处 | 别处是什么 |
|---|---|---|
| 篇幅档、容量核算、格位表怎么排 | `01c` 四、五 | 主文件只列入口，本页只列档位与结论 |
| 时间轴唯一口径、两道硬闸门、章首工作注格式 | `12` | `01c` 只讲格位怎么排；本页只给结论 |
| 六行表、全书级三查、验收清单十二项、开写条件十条、审稿意见三档处置 | `05` 一、二、六、十 | 主文件与 `08` 只做入口 |
| 情感落点表模板 | `10` 第五节 | `08` 明写「本节不存副本」 |
| 人物卡、情节主表、案目标清单、常量与伏笔台账等表模板 | `08` 第三节 | 别处一律不存副本 |
| 章级强度曲线与章末钩位置 | `13` | 主文件只做分流 |
| 反馈地址与四条硬规矩 | `14` | 主文件「反馈与隐私」节同步一份，冲突以 `14` 为准 |

**两处说法不一致时，以本表权威处为准，把另一处改成指针**——加规则容易，删重复难；重复留着，迟早长成两个口径。

**术语对照：全称、简称、层级，别当成三样东西**（只登记实际在用的叫法，不新造词）：

| 正式叫法 | 简写／别称 | 是什么关系 | 权威处 |
|---|---|---|---|
| 情节主表 | 主表 | 同一张表，简称 | `08` 三 |
| 常量与伏笔台账 | 台账 | 同一张表；**全库只用全称**，不单独写「常量台账」 | `08` 三 |
| 章首时间线工作注 | 章首工作注 | 后者是统称，每章一张；填表格式在 `12` 第四节 | `12` 四 |
| 情绪强度曲线 | 强度 | 后者是口语简称 | `13` 二 |
| 千字强度 | — | **不是「强度」的同义词**：情绪打分除以汉字数，消除章长差异 | `13` 二 |
| 场面戏 | 场面 | 同一类戏，简称 | `01a` |
| 承重边 | 核心关系边 | 同一件事，全书统一叫「承重边」 | `01b` |
| 核心脾气＋三件事＋固定代价 | 核心机制 | 后者是统称，前者是它的落地格式 | `01a` |
| 格位表 | 格位（口语） | 格位表是表，格位是其中一行 | `01c` 四 |
| 承受驱动型／目标驱动型 | 旧称「承受型」「承受驱动」「目标驱动」 | **同一件事的旧叫法，已废弃**；全库统一用带「型」的全称，与「台账型／爽点型」一致 | `SKILL.md` 第一件事、`01a` 二之附 |

**两条容易漏的口径**：

- **文风能换吗**：能。立项一页纸填了「文风五维」并冻结样本＝对标档，句长／对话比／去 AI 味词表以样本为准；没填＝默认档（冷叙事铁律）。见 `08` 第五节文风五维表、`03` 开头。换文风不换结构纪律。
- **伏笔埋了多久该收**：超过十章没兑现的进超期清单，逐条判收或删，不硬凑兑现。见 `08` 第三节常量与伏笔台账。

## 四、高频问答

**问：一定要写格位表吗？**
长篇要，中篇简化（格数≈章数），短篇不跑。见 `01c`。

**问：脚本报红就是稿子不合格吗？**
不是。脚本是量具不是判具：`check_text` 判不出极端注水，`check_emotion` 判不出「标签合规但正文没兑现」，`check_timeline` 判不出地点倒挂。全绿不等于过关，须人工通读。

**问：一章该写多少字？**
按渠道分两档：**连载平台**按平台章（两三千字）；**出版向、征文向、冷叙事与零度写法**按实测，常在一千到一千五。别拿平台章的数去卡冷叙事——目标会撑大一倍，落笔永远补不上。做法：前三章写完，用实测单章字数 × 计划章数回算总量，与纸面目标比，低了就改档或改章数（`01c` 第 5 条）。

**问：AI 写的读起来假怎么办？**
先看 `03-文笔纪律.md` 的句长趋势与孤行，再查 `10-文笔与情感层.md` 的情感四来源，最后才动结构。

**问：同一个问题反复出现？**
按 `14` 整理一段反馈；若属多线抢槽，看 `09-仲裁层.md` 的元优先级。

**问：能不能直接替我写完？**
不能。本技能给结构、判据和检查工具，成稿仍由人写。

**问：技能这么大，会不会很慢？**
主文件只有百余行，规则按阶段只读 1—2 份细则，不会一次加载全部。资料多，但不必通读。
