# 十二、故事时间线（跨切验收层·唯一口径）

> 定位：与 `references/09-仲裁层.md`、`references/10-文笔与情感层.md` 同层的**验收层**，不新增发电机、不改开写条件十条的宽严、不增删终局四型、不扩调色板。
> 管一件事：**正文写出来的时间，能不能折算回格位表**。
> 为什么单立一层：`01c` 第四节管「格位表这张表怎么排」，`05` 验收第 5 项与开写条件第 5 条验的也是格位表自身；
> **正文一侧从来没有任何约束**，于是格位表按每格隔四天铺日期、正文按「第 N 天」连续计时，两套轴并存，谁也管不着谁。

## 一、唯一时间轴（硬约束，不可豁免）

1. **格位表的年月日是全书唯一时间基准。** 每一章在落笔前先查本章挂的格号与日期，记进章首工作注（工作注不进正文）。
2. **正文不许自建第二套计时轴。** 尤其不许用「第 N 天／第几天」从头到尾连续计数——那是与格位表并列的第二根轴，两套轴必然打架。
3. **正文任何时间表达，必须能折算回一个格位号或格位区间。** 折算不出的，不许写；宁可写「过了些日子」「开春那阵」，不许写一个没有起算点的硬天数。
4. **有冲突时，以格位表为准，改正文不改表。** 格位表、主表、大纲、台账是设计层定稿；正文是落笔实现。发现不一致，第一反应必须是「正文哪句写错了」，不是「把表改成正文那样」。确需改表，须显式裁定并全量回归（按编号反查所有引用），不得局部顺手改一格。
5. **每格日期是「该章起日锚点」，不是该章时长上限。** 一章可以覆盖**本格日期起、到相邻格日期之前**的连续若干日（章内跨日合法，如台阶上蹲两天），但必须：①在章首工作注写明本章起日与覆盖日数；②**不得等于或越过相邻格日期**（越界就侵了下一章的时间）；③章内时段只许顺流。这不算「自建第二套计时轴」——起算点仍是格位表，只是本格内顺延。反过来，把一格读成「只准发生一天」也是错的，会逼着把合法的章内跨日判成硬伤。
6. **一章合并覆盖多格，必须在格位表加「章」列声明。** 一章吃掉两格（首章超配、一案多格并成一章）是合法写法，但"相邻格"到底指哪一格就成了歧义：量具默认按「第 k 章 ↔ 第 k 格」一一对应，一旦某章覆盖两格，后面所有章的相邻格全部错位一格，把合法的「第二天」报成"侵了下一章"。**处置：在格位表加一列「章」，该行的值写「第 N 章」**，量具即按声明取"本章末格之后那一格"作相邻格。不加该列也能跑，但落点恰好等于相邻格日的会报【待核】而非【警报】，须人判是哪一种。

## 二、四类时间表达的唯一填法

| 类型 | 例 | 折算规则 | 禁用 |
|---|---|---|---|
| **绝对日期** | 「1979-03-12」「一九七九年开春」 | 须落在格位表该卷日期区间；写到日的必须与本章格位日期一致。年／季节只作概括，不得与格位日期矛盾 | 与本章格位日期冲突；正文自造一个格位表里没有的日子 |
| **相对计时** | 「第三天」「隔了一天」「三天后」「回来的第三天」 | 必须给出**起算点**（哪一格、哪件事之后），且按**格位表日期差**算，不按叙述顺延、不按章数累加 | 全书连续「第 N 天」计数；没有起算点的硬天数；跨出本章覆盖区间 |
| **时段** | 「第二天傍晚」「后半夜」「天没亮」 | 须归属本章覆盖区间内的某一天；**章内跨日的「第二天」＝本格起日＋1**，记进章首工作注即可，**不等于也不越过相邻格日期**。同章内时段只许顺流 | 时段倒流（后半夜→当天清早）；已起身走了又写「还坐着」；越过相邻格日期 |
| **跨章时间量** | 「煤够烧九天」→「还剩四天」 | 进 `08` 常量与伏笔台账的**时间量**类，每次递减按**格位表日期差**核算，不按章数核；改一处按编号反查所有含它的章 | 拿章数当天数；只减不改起算日 |

**换算例一·跨章时间量**（2026-11 长线稿实测错法）：格位表相邻两格差 5 天，「够烧九天」在第 3 天起算，到第 8 天应为 9−5＝**4 天**；写成「五天」是拿叙述天数顶了格位日期。同批实测还出过：正文按「第 N 天」连续计数而格位表按四天一跳（双轴）、同一趟回程写两遍、起身走了下一句还坐着——这三类都是本章要防的。

**换算例二·章内跨日（合法）**：格 8＝1979-04-14、格 9＝1979-04-18，第 9 章挂格 8。细纲写「台阶上蹲两天」、正文写「第二天傍晚，他还坐着」——本格起日 4/14，章内跨到 4/15，仍在相邻格 4/18 之前，**合法**；章首工作注记「起日 4/14，覆盖 2 日」即可。旧稿曾要求「跨日的第二天必须等于相邻格位日」＝4/18，把合法的章内跨日逼成硬伤，该口径**已废**。真正的错是：写成「第五天傍晚」（越过 4/18，侵了下一章的时间），或全章十章按「第 N 天」连续计数（另起一根轴）。

## 三、跨章状态连续三查（人工，脚本抓不到）

每写完一章、每插一段新事件，都要回上一章末核这三样：

1. **地点连续**：本章开头人物所在地点＝上一章结尾地点。A 到 B 的回程**只写一次**；不许上一章已夜车回厂、下一章又在省城招待所再赶一趟头班车。
2. **动作状态连续**：上一章末的身体姿态／动作，是本章开头的起点。站起来了、走到街口了，下一句不能「他还坐着」；同一时段两章不能一个写「回办公室把门关上」、一个写「没回办公室」。
3. **在场一致**：格位表「在场人」列与正文实际出场对齐；「从省城回来的第三天」这类句，须与本章人物**此刻仍在省城**不矛盾。

这三样**没有脚本能可靠判定**（反例压力测试已证明结构代理可被贴标签绕过），只能逐章对读。规矩是：**跑完脚本不等于时间线过关**。

## 四、两道硬闸门（①写单章前预检／②写完后回验）

**① 写单章前·时间线预检**（不进下一章就不算过）：
- 本章挂哪个格号、哪个日期？
- 上一章结尾：人在哪、什么姿态、手里有什么？
- 本章要出现的时间表达，逐句折算回格位日期，列成一张三列表（原句／折算到哪一格／依据）。

答不出任一条，不许落笔。

### 章首时间线工作注（① 的落地格式，每章一张）

`05` 开写条件第 5 条要求「不许自建第二套计时轴」钉进章首工作注。工作注是**设计层文件，不进正文、不改定稿表**；每章一张，落笔前填、改稿后回填。十章缺这张表，第 5 条就只能记「部分」——不是故事错，是验收没有载体。

| 项 | 填什么 |
|---|---|
| 章号／主表编号／格号 | 第 N 章、一-0N、格 N |
| 本格起日／相邻格日期 | 格位表里该格与下一格的年月日；本章覆盖区间＝[起日, 相邻格日) |
| 覆盖日数 | 章内跨几天；只一天写 1。写「起日＋覆盖日数」，不另起一套计数 |
| 上章结尾状态 | 地点、身体姿态、手里有什么（三查① ②的起点） |
| 本章时间表达折算表 | 三列：正文原句／折算到哪一天／依据（哪一格＋第几日） |
| 三查结论 | 地点连续／动作状态连续／在场一致，逐项记过或部分 |

**填写样例**（用真实数据，仅示意格式，不代表任何一稿已填）：

| 项 | 内容 |
|---|---|
| 章号／编号／格号 | 第 9 章、一-09、格 8 |
| 本格起日／相邻格 | 1979-04-14／1979-04-18（覆盖 4/14—4/17） |
| 覆盖日数 | 2 日（起日 4/14，章内顺延到 4/15） |
| 上章结尾状态 | 省城机关台阶，坐着，布包搁膝头、搪瓷缸在手边 |
| 折算表 | 「第二天他还是那级台阶」→4/15（格 8 起日＋1）；「第二天傍晚，他还坐着」→4/15 傍晚（同上，章内顺流）；无绝对日期、无「第 N 天」全书计数 |
| 三查结论 | 地点连续过；动作状态连续过（起身离场已删）；在场一致按设计层留痕记部分 |

**工作注不进正文**：它是给作者与核账用的外部文件；正文里不留格号、日期、折算依据。跑 `scripts/check_timeline.py` 出的待核清单，逐条并进这张表。

**② 改稿／扩写后·跨章回归**（这条是血案换来的）：
- **不许只跑 `scripts/check_text.py` 就宣布对齐**。文笔脚本只认句长、引号、孤行，不认日期、地点、人物身份、台账。
- 每插一组新事件，必须回核：前后各一章的时间表达、地点与动作状态、常量与伏笔台账里所有带该编号的行、主表与格位表的对应行。
- 跑 `scripts/check_timeline.py 格位表.md 正文目录/` 出机械清单；再按上面「三查」人工逐章对读。
- **定稿优先**：正文是唯一可改一侧。发现冲突先改正文，别反向改定稿表。

## 五、可跑检查与能力边界

`scripts/check_timeline.py 格位表.md 正文目录/` 只做四件机械可靠的事：

1. 格位表日期序列：零倒序、首末日期、相邻间隔分布（间隔不均是合法的，只报告不判错）。
2. 正文里出现的**绝对日期／年份**是否落在格位表区间内；出现格位表里没有的日期即报「待核」。
3. **章内跨日合法／越界**：每个「第 N 天」按「本格起日＋(N−1)」折算落点，落在相邻格日期之前即判「章内跨日，合法」，越过即报「侵了下一章的时间」；脚本逐条打印折算落点。
4. 正文里出现**跨章递增的「第 N 天」计数**时，与格位表相邻间隔对照，报「双轴警报」——两套时间轴并存的高置信信号。
   **单章内出现「第二天」不算双轴**：那是本格起日＋1 的章内跨日，按第 3 条判合法，只提示补章首工作注。旧稿把章内跨日一律折算成相邻格日期，已废。

**明确抓不到**：地点倒挂、动作状态断裂、同一时段互斥、人物位置错、「回来的第三天」这类语义矛盾、相对计时有没有起算点。
脚本输出的是**待核清单**，不是合格证明。全绿只说明「没抓到机械信号」，第三节三查仍须人工做。

## 六、与其他层的关系（防重复、防漂移）

| 已有条款 | 管什么 | 本层不重复 |
